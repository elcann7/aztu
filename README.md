## 🚀 Layihə Haqqında

Bu platforma AzTU 6326A2 qrup tələbələrinin gündəlik dərslərini, laboratoriya işlərini, mühazirə qeydlərini, imtahan hazırlıqlarını və qarşılıqlı sual-cavablarını tək mərkəzdən idarə etmək üçün yaradılmışdır. WhatsApp və Telegram qruplarında it-bata düşən dərs materialları, mühazirələrdə müəllimlərin vurğuladığı vacib məqamlar və vaxtı keçən tapşırıqlar burada kateqoriyalı şəkildə saxlanılır.

Platforma **Linear** və **21st.dev** dizayn fəlsəfəsindən ilhamlanaraq müasir, təmiz və sürətli interfeysə malikdir.

## ✨ Əsas Xüsusiyyətlər

1. **Rəsmi Google Identity Services (GIS) & E-poçt Girişi**:
   - Google ilə bir toxunuşla (`One Tap` / Rəsmi Google düyməsi) tələbə hesabı ilə giriş.
   - Standart universitet e-poçtu və şifrə ilə qeydiyyat.
2. **Qrup Mühafizəsi və Kvota Limiti**:
   - **Maksimum 30 Nəfər**: Kənar şəxslərin daxil olmaması üçün qeydiyyat 30 tələbə ilə məhdudlaşdırılıb.
   - **6326A2 Təhlükəsizlik Kodu**: Giriş və qeydiyyat zamanı qrup kodu mütləq tələb olunur.
3. **Təsdiqlənmiş Tələbə Profili**:
   - Tələbənin **Adı**, **Soyadı** və **Qrupu** universitet qeydiyyatı ilə təsdiqlənir və dəyişdirilməsi bloklanır (LOCKED).
   - Profil şəkli yükləmə, hazır akademik avatarlar və Google profil şəkli inteqrasiyası.
   - Bio/status, Tələbə bilet nömrəsi, İxtisas, Telegram, Əlaqə nömrəsi və GitHub linki əlavə etmə imkanı.
4. **Fənn Portalları (Course Shells)**:
   - **Riyazi analiz** (MATH-101)
   - **Fizika** (PHYS-102)
   - **Proqramlaşdırma** (CS-101)
   - **İngilis dili** (ENG-101)
   - Sillabus, həftəlik mühazirələr, slaydlar və kolloqvium materialları.
5. **Qrup Qeydləri (Timeline)**:
   - Müəllimlərin dərslərdə xüsusi vurğuladığı qeydlər ("Müəllim dedi"), imtahan ipucları, seminar tələbləri.
   - "Bugün", "Dünən" və tarixlərə görə avtomatik qruplaşdırma.
6. **Sual-Cavab (Q&A Board)**:
   - Tələbələrin çətinlik çəkdiyi sualları paylaşması, cavablandırması və həll olunmuş qeyd etməsi.
   - Sual və cavablara səsvermə (Upvote) sistemi.
7. **Sorğular (Polls)**:
   - Qrupdaxili qərarlar üçün demokratik səsvermə (məsələn, dərs saatlarının dəyişdirilməsi, təqdimat günləri).
   - Real-vaxt faiz qrafikləri.
8. **Akademik Materiallar Kataloqu**:
   - Dərsliklər, PDF təqdimatlar, laboratoriya rəhbərlikləri, fənlər üzrə filtrasiya.
9. **Deadline-lar və Təqvim**:
   - Laboratoriya işləri, sərbəst işlər və kolloqviumlar üçün geri sayım sayğacı və təcililik rəngləri (Yüksək, Orta, Aşağı).
10. **İnteqrasiya Olunmuş Python Sandbox**:
    - Proqramlaşdırma fənni üçün brauzerdaxili Python kod redaktoru və icra mühiti.
11. **React Portal Modalları**:
    - Bütün modallar birbaşa `document.body`-yə mount olunur, ekran ölçüsündən asılı olmayaraq başlıq və idarəetmə düymələri heç vaxt kəsilmir.
12. **İnteraktiv Su Simulyasiyası**:
    - Fizika laboratoriyasında damlalarla dalğa yaratmaq, maneə çəkmək, yağış/fırtına rejimlərini sınamaq və nəticəni PNG olaraq saxlamaq.

## 🛠 Texnologiya Yığını

| Sahə | Texnologiya | İzah |
| :--- | :--- | :--- |
| **Frontend Freymvork** | React 19 (TypeScript) | Komponent əsaslı, müasir tip təhlükəsiz memarlıq |
| **Bina Aləti** | Vite 6 | İldırım sürətli HMR və optimallaşdırılmış istehsal paketi |
| **Dizayn Sistemi** | Pure Vanilla CSS | HSL rəng palitrası, glassmorphism, responsive qridlər |
| **İkonlar** | Lucide React | Təmiz və müasir vektor ikon dəsti |
| **Autentifikasiya** | Google GIS + Web Crypto | Google Identity Services API və SHA-256 şifrələmə |
| **Vəziyyət İdarəetməsi** | React Context API | `AuthContext`, `DatabaseContext`, `RouterContext` |
| **Hosting & CI/CD** | Vercel | Avtomatik SPA yönləndirmə və qlobal CDN yerləşdirmə |

## 🔒 Təhlükəsizlik və Məxfilik Sistemi

- **30 Tələbə Limiti**: `AuthContext`-də qeydiyyatdan keçmiş tələbə sayı daimi monitorinq olunur. Say 30-a çatdıqda qeydiyyat avtomatik olaraq kilidlənir.
- **Qrup Kodu Təsdiqi (`6326A2`)**: Qeydiyyat və Google ilə ilk girişdə qrup şifrəsi olmadan hesab yaradıla bilməz.
- **Şifrə Təhlükəsizliyi**: Şifrələr Web Crypto API vasitəsilə gizli salt ilə SHA-256 alqoritmində heşlənir.
- **Şəxsiyyətin Dəyişdirilməzliyi**: Tələbələrin rəsmi Adı və Soyadı profil pəncərəsində kilidlənir (read-only), saxtakarlığın qarşısı alınır.

## 📂 Qovluq Strukturu

```
AzTu/
├── public/                 # Statik resurslar və favicon
├── src/
│   ├── assets/             # Qrafik resurslar
│   ├── components/         # Ümumi və təkrar istifadə olunan komponentlər
│   │   ├── common/         # Portal Modal, kartlar və bazis elementlər
│   │   └── app/            # Vahid iş sahəsinin daxili komponentləri
│   │       ├── modals/     # Qeyd, Sual, Sorğu, Material və Profil modalları
│   │       ├── views/      # Qeydlər, Materiallar, Deadline, QA, Sorğu və Sandbox
│   │       ├── Sidebar.tsx # Sol naviqasiya paneli
│   │       ├── TopBar.tsx  # Yuxarı idarəetmə və axtarış paneli
│   │       └── AppShell.tsx# Əsas iş mühiti konteyneri
│   ├── context/            # Qlobal vəziyyət (Auth, Database, Router)
│   ├── hooks/              # Xüsusi hook-lar (useScrollReveal və s.)
│   ├── pages/              # Giriş və Qeydiyyat səhifələri
│   ├── services/           # Google Auth və xarici inteqrasiya xidmətləri
│   ├── styles/             # Qlobal dizayn sistemi, dəyişənlər və animasiyalar
│   ├── types/              # TypeScript interfeysləri və verilənlər modelləri
│   ├── App.tsx             # Marşrut idarəedici və əsas giriş nöqtəsi
│   └── main.tsx            # React DOM renderi
├── .env                    # Ətraf mühit dəyişənləri (Google Client ID)
├── vercel.json             # Vercel SPA 404 rewrite konfiqurasiyası
└── package.json            # Layihə asılılıqları və skriptlər
```

## 💻 Quraşdırma və İşə Salma

### 1. Repozitoriyanı klonlayın:
```bash
git clone https://github.com/elcann7/aztu.git
cd aztu
```

### 2. Asılılıqları quraşdırın:
```bash
npm install
```

### 3. Ətraf mühit dəyişənlərini təyin edin:
`.env` faylını redaktə edərək Google Client ID-ni daxil edin:
```env
VITE_GOOGLE_CLIENT_ID=1094028904596-62m7kvd52j3ajbvhn6pl25lord2tqo74.apps.googleusercontent.com
```

### 4. Lokal serveri başladın:
```bash
npm run dev
```
Brauzerdə açın: `http://localhost:5173`

### 5. İstehsalat (Production) üçün build edin:
```bash
npm run build
```
